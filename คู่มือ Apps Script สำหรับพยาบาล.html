บทที่ 1

Google Apps Script คืออะไร

Apps Script คือเครื่องมือฟรีจาก Google ให้เราเขียนโปรแกรมเล็ก ๆ ทำงานกับ Google Sheets, Docs, Gmail, Drive และสร้างเว็บแอปได้ Google เรียกมันว่าแพลตฟอร์ม JavaScript บนคลาวด์ที่ทำงานบน Google Drive[1]

ทำไมมือใหม่ถึงชอบ

ไม่ต้องติดตั้ง

เขียนโค้ดในเบราว์เซอร์ โค้ดเก็บใน Drive และทำงานบนเซิร์ฟเวอร์ของ Google[2]

มีฐานข้อมูลให้แล้ว

ใช้ Google Sheets เป็นที่เก็บข้อมูล หน้าตาคุ้นเคยเหมือน Excel

มีที่ตั้งแอปฟรี

กด Deploy แล้วได้ลิงก์เปิดผ่านเบราว์เซอร์ทันที[3]

คุมคนเข้าได้

เลือกได้ว่าเปิดเฉพาะเรา คนในองค์กร หรือคนที่มีบัญชี Google

เทียบกับแอปที่ทำใน Claude หรือ ChatGPT

เรื่องแอปหน้าเดียวจาก Claude/ChatGPTเว็บแอป Apps Script
เก็บข้อมูลรวมกันหลายคนไม่ได้ เก็บได้แค่ในเครื่องเดียวได้ ทุกคนบันทึกลงชีตแผ่นเดียวกัน
เหมาะกับเครื่องคำนวณ แบบประเมินคะแนนบันทึกประจำเวร เช็กลิสต์ นับสต็อก
ความยากง่ายมากปานกลาง ต้องคัดลอกโค้ดไปวางเอง
สรุปสั้น ๆถ้าแอปต้อง จำข้อมูลและใช้ร่วมกันทั้งหอ Apps Script คือก้าวถัดไปที่ง่ายที่สุด

บทที่ 2

ข้างในแอปมีอะไรบ้าง

เว็บแอป Apps Script มี 5 ส่วนเหมือนที่เรียนในคลาส แต่เราเขียนเองแค่ 2 ไฟล์ คือ Index.html กับ Code.gs ที่เหลือ Google เตรียมไว้ให้

สองคำที่ต้องรู้จัก

doGet = ประตูหน้าบ้าน

ทุกครั้งที่มีคนเปิดลิงก์แอป Apps Script จะเรียกฟังก์ชันชื่อนี้ สคริปต์ที่เป็นเว็บแอปได้ต้องมี doGet(e) หรือ doPost(e)[3]

google.script.run = พนักงานรับออเดอร์

ให้หน้าเว็บสั่งงานโค้ดใน Code.gs ทำงานแบบไม่รอคำตอบ จึงต้องบอกด้วยว่าสำเร็จแล้วทำอะไร (withSuccessHandler) และพังแล้วทำอะไร (withFailureHandler)[4]

สคริปต์มี 2 แบบBound script สร้างจากในชีตด้วยเมนู ส่วนขยาย (Extensions) > Apps Script ติดอยู่กับชีตนั้น ใช้สิทธิ์เดียวกับชีต คู่มือนี้ใช้แบบนี้[6] ส่วน Standalone script สร้างจาก Drive ไม่ผูกกับไฟล์ไหน
ระวังคนที่มีสิทธิ์แก้ชีตใครแก้ชีตได้ ก็เปิดและรันโค้ดได้ด้วย ส่วนคนที่ดูได้อย่างเดียวเปิดตัวแก้โค้ดไม่ได้[6] และฟังก์ชันที่ชื่อลงท้ายด้วย _ หน้าเว็บจะเรียกใช้ไม่ได้[4]

บทที่ 3

เตรียมของให้พร้อม

เรื่องเดียวที่ต้องตัดสินใจก่อนเริ่ม คือจะใช้บัญชี Google แบบไหน เพราะชีตที่เก็บข้อมูลและตัวแอปจะเป็นของบัญชีนั้น

บัญชีเหมาะกับข้อควรรู้
ส่วนตัว (@gmail.com)ฝึกหัด ทดลอง แอปที่ไม่มีข้อมูลอ่อนไหวขีดจำกัดต่ำกว่า ข้อมูลอยู่ในบัญชีส่วนตัว
องค์กร (Google Workspace ของ รพ.)แอปที่ใช้ในหน่วยงานจริงจำกัดให้เฉพาะคนในองค์กรได้ แต่ผู้ดูแลระบบอาจปิด Apps Script ไว้ ถาม IT ก่อน
ลำดับที่แนะนำฝึกด้วยบัญชีส่วนตัวและข้อมูลสมมติก่อน พอจะใช้จริงในหอ ค่อยสร้างใหม่ในบัญชีองค์กรตามที่ฝ่าย IT อนุญาต

อุปกรณ์

  • โน้ตบุ๊ก + Chrome: ใช้สร้างและแก้โค้ด หน้าแก้โค้ดใช้บนแท็บเล็ตไม่สะดวก
  • แท็บเล็ตหรือมือถือ: ใช้ทดสอบเหมือนผู้ใช้จริง
  • ภาษาเมนู: คู่มือเขียนทั้งชื่อไทยและอังกฤษ หน้าแก้โค้ดส่วนใหญ่เป็นภาษาอังกฤษ

บทที่ 4

เส้นทาง 10 ขั้น

แอปทุกตัวเดินตาม 3 ช่วงนี้ ช่วงแรกทำบนกระดาษก่อนแตะคอมพิวเตอร์ และขั้น 5–8 จะวนซ้ำหลายรอบเสมอ เป็นเรื่องปกติ

ช่วง A · วางแผนบนกระดาษ

  1. นิยามปัญหาและ MVP ใครใช้ แก้ปัญหาอะไร เวอร์ชันแรกต้องทำอะไรได้
  2. ออกแบบตารางข้อมูล แต่ละช่อง = หัวคอลัมน์ในชีต ห้ามมีช่องข้อมูลสีแดง (บทที่ 8)

ช่วง B · สร้างบนโน้ตบุ๊ก

  1. สร้าง Google Sheets ใส่หัวคอลัมน์แถวแรก
  2. เปิดตัวแก้โค้ด จากเมนู ส่วนขยาย (Extensions) > Apps Script
  3. ให้ AI เขียนโค้ด Code.gs และ Index.html ด้วย Prompt ในบทที่ 6
  4. วางโค้ด บันทึก อนุญาตสิทธิ์ รันฟังก์ชันหนึ่งครั้งจากตัวแก้โค้ดเพื่อให้หน้าขอสิทธิ์ขึ้น[8]
  5. เปิดลิงก์ทดสอบ Deploy > Test deployments[3]
  6. ทดสอบตามเช็กลิสต์ เจอปัญหา → สั่ง AI แก้ → วนกลับขั้น 5

ช่วง C · ใช้งานจริง

  1. Deploy เป็นเว็บแอป Deploy > New deployment > Web app ได้ลิงก์ลงท้าย /exec[3]
  2. แชร์และดูแล แก้โค้ดแล้วต้อง Deploy เป็นเวอร์ชันใหม่ ไม่งั้นลิงก์เดิมยังเป็นโค้ดเก่า[10]
จำง่าย ๆลิงก์ทดสอบ (/dev) = เห็นโค้ดล่าสุดเสมอ ใช้ได้เฉพาะคนสร้าง · ลิงก์ /exec = เวอร์ชันที่เผยแพร่แล้ว ให้คนอื่นใช้

ลบโค้ดเดิมใน Code.gs ทั้งหมด วางโค้ดด้านล่าง แล้ว แทนคำว่า วาง_ID_ของชีตที่นี่ ด้วย ID จากขั้นที่ 1 (เก็บเครื่องหมาย ' ' ไว้) จากนั้นกด Ctrl+S เพื่อบันทึก

Code.gs 
// ===== ตั้งค่า (แก้ได้) =====
const SPREADSHEET_ID = 'วาง_ID_ของชีตที่นี่';
const SHEET_NAME = 'บันทึก';
const MIN_TEMP = 2;   // อุณหภูมิต่ำสุดที่ยอมรับ (°C)
const MAX_TEMP = 8;   // อุณหภูมิสูงสุดที่ยอมรับ (°C)

// เปิดหน้าเว็บเมื่อมีคนเข้าลิงก์
function doGet() {
  return HtmlService.createHtmlOutputFromFile('Index')
    .setTitle('บันทึกอุณหภูมิตู้เย็นยา')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1');
}

// หาแผ่นงาน ถ้ายังไม่มีให้สร้างพร้อมหัวคอลัมน์
// ชื่อลงท้ายด้วย _ = หน้าเว็บเรียกใช้ไม่ได้
function getSheet_() {
  const ss = SpreadsheetApp.openById(SPREADSHEET_ID);
  let sheet = ss.getSheetByName(SHEET_NAME);
  if (!sheet) {
    sheet = ss.insertSheet(SHEET_NAME);
    sheet.appendRow(['วันที่เวลา', 'ตู้', 'อุณหภูมิ (°C)', 'สถานะ', 'ผู้บันทึก', 'หมายเหตุ']);
  }
  return sheet;
}

// รันครั้งแรกจากตัวแก้โค้ด เพื่ออนุญาตสิทธิ์และสร้างแผ่นงาน
function setup() {
  getSheet_();
}

// บันทึก 1 รายการ (หน้าเว็บเรียกผ่าน google.script.run)
function saveRecord(form) {
  const temp = Number(form.temp);
  if (!form.fridge || form.temp === '' || isNaN(temp) || !form.initials) {
    throw new Error('กรุณากรอกข้อมูลให้ครบและถูกต้อง');
  }
  const status = (temp < MIN_TEMP || temp > MAX_TEMP) ? 'นอกช่วง' : 'ปกติ';
  getSheet_().appendRow([new Date(), form.fridge, temp, status, form.initials, form.note || '']);
  return status;
}

// ดึง 10 รายการล่าสุดมาแสดง
function getRecent() {
  const sheet = getSheet_();
  const last = sheet.getLastRow();
  if (last < 2) return [];
  const start = Math.max(2, last - 9);
  const rows = sheet.getRange(start, 1, last - start + 1, 5).getValues();
  return rows.reverse().map(function (r) {
    const time = r[0] instanceof Date
      ? Utilities.formatDate(r[0], 'Asia/Bangkok', 'dd/MM/yyyy HH:mm')
      : String(r[0]);
    return [time, r[1], r[2], r[3], r[4]];
  });
}
อ่านออกก็พอdoGet เปิดหน้า Index · saveRecord ตรวจข้อมูลแล้วเติมแถวใหม่ด้วย appendRow · getRecent อ่าน 10 แถวล่าสุดด้วย getRange กับ getValues[7] · วันที่ถูกแปลงเป็นข้อความก่อนส่งกลับไปหน้าเว็บ
ศัพท์ในหน้านี้
const
ค่าคงที่ แก้ได้ที่บรรทัดเดียว เช่น ช่วงอุณหภูมิ
Comment
บรรทัดอธิบายที่ขึ้นต้นด้วย // คอมไม่อ่าน
appendRow
คำสั่งเติมแถวใหม่ต่อท้ายชีต
getValues
คำสั่งอ่านค่าในช่วงเซลล์ออกมาเป็นตาราง
Error
ข้อความแจ้งว่าผิดพลาดตรงไหน

<script>
  const form = document.getElementById('f');
  const btn = document.getElementById('btn');

  form.addEventListener('submit', function (e) {
    e.preventDefault();
    btn.disabled = true;
    btn.textContent = 'กำลังบันทึก...';
    google.script.run
      .withSuccessHandler(function (status) {
        if (status === 'ปกติ') {
          showMsg('บันทึกแล้ว: อุณหภูมิอยู่ในช่วงปกติ', false);
        } else {
          showMsg('บันทึกแล้ว: อุณหภูมินอกช่วง โปรดแจ้งผู้รับผิดชอบ', true);
        }
        form.reset();
        resetButton();
        loadRecent();
      })
      .withFailureHandler(function (err) {
        showMsg('บันทึกไม่สำเร็จ: ' + err.message, true);
        resetButton();
      })
      .saveRecord(form);
  });

  function resetButton() {
    btn.disabled = false;
    btn.textContent = 'บันทึก';
  }

  function showMsg(text, warn) {
    const m = document.getElementById('msg');
    m.textContent = text;
    m.style.color = warn ? '#B0342A' : '#136F57';
  }

  function loadRecent() {
    google.script.run.withSuccessHandler(function (rows) {
      const t = document.getElementById('recent');
      t.innerHTML = '<tr><th>เวลา</th><th>ตู้</th><th>°C</th><th>สถานะ</th><th>ผู้บันทึก</th></tr>';
      rows.forEach(function (r) {
        const tr = document.createElement('tr');
        r.forEach(function (v) {
          const td = document.createElement('td');
          td.textContent = v;
          tr.appendChild(td);
        });
        t.appendChild(tr);
      });
    }).getRecent();
  }

  loadRecent();
</script>
</body>
</html>

ขั้นที่ 5 · รัน setup และอนุญาตสิทธิ์

  1. เปิด Code.gs เลือกฟังก์ชัน setup ที่แถบด้านบน แล้วกด Run
  2. กด Review permissions แล้วเลือกบัญชีของตัวเอง
  3. เจอหน้า "Google hasn't verified this app" ให้กด Advanced > Go to [ชื่อโปรเจกต์] (unsafe) > Allow[11]
  4. กลับไปดูชีต ต้องเห็นแท็บใหม่ชื่อ "บันทึก" พร้อมหัวคอลัมน์
กด Advanced ได้เฉพาะโค้ดของเราเองApps Script สแกนโค้ดแล้วขอสิทธิ์เท่าที่โค้ดใช้[8] แอปนี้ขอแค่สิทธิ์เข้า Google Sheets ห้ามทำแบบนี้กับสคริปต์ที่คนอื่นส่งมาโดยไม่รู้ที่มา

ขั้นที่ 6 · ทดสอบด้วยลิงก์ทดสอบ

Deploy > Test deployments > เลือก Web app > กด Copy ใต้ลิงก์ แล้วเปิดในเบราว์เซอร์[3] ลอง 3 กรณี: 5 °C (ปกติ) · 9.5 °C (นอกช่วง) · เว้นว่าง (ต้องบันทึกไม่ได้)

ขั้นที่ 7 · Deploy เป็นเว็บแอป

  1. Deploy > New deployment > กดรูปเฟือง > Web app
  2. Description พิมพ์ "v1 เวอร์ชันแรก"
  3. Execute as: Me สคริปต์ทำงานในนามเจ้าของเสมอ[3] ผู้ใช้จึงบันทึกได้โดยไม่ต้องแชร์ชีตให้ทุกคน
  4. เลือก Who has access ตามตาราง แล้วกด Deploy คัดลอกลิงก์ที่ลงท้าย /exec
Who has accessใครเปิดได้คำแนะนำ
Only myselfเฉพาะเจ้าของตอนทดสอบ
Anyone within [องค์กร]คนที่ใช้บัญชีองค์กรเดียวกัน (มีเฉพาะบัญชี Workspace)แนะนำสำหรับใช้ในหอ
Anyone with Google accountใครก็ได้ที่ล็อกอิน Googleเมื่อไม่มีบัญชีองค์กร และแอปไม่มีข้อมูลอ่อนไหว
Anyoneทุกคนที่มีลิงก์ ไม่ต้องล็อกอินหลีกเลี่ยงสำหรับแอปที่บันทึกข้อมูล

ขั้นที่ 8 · เปิดบนแท็บเล็ต

ส่งลิงก์ /exec เข้าแท็บเล็ต แล้วเพิ่มไว้ที่หน้าจอหลัก (Chrome: เมนู ⋮ > เพิ่มลงในหน้าจอหลัก · Safari: ปุ่มแชร์ > เพิ่มไปยังหน้าจอโฮม) จะได้ไอคอนเปิดแอปได้ทันที

ขั้นที่ 9 · อัปเดตโดยใช้ลิงก์เดิม

แก้โค้ดทุกครั้ง: Deploy > Manage deployments > รูปดินสอ > Version เลือก New version > Deploy ลิงก์ /exec เดิมจะใช้โค้ดใหม่ทันที (ถ้ากด New deployment จะได้ลิงก์ใหม่แทน)

สคริปต์ทำงานในนามใคร

สั่ง AI ให้เขียน Apps Script

ใช้สูตร Prompt 6 ส่วนเดิมจากคลาส (บทบาท → ปัญหา → ฟีเจอร์ → ข้อมูล → หน้าตา → ข้อจำกัด) แล้วเพิ่ม ส่วนที่ 7: ข้อกำหนดทางเทคนิคของ Apps Script เพราะถ้าไม่บอก AI มักเขียนเว็บแอปทั่วไปที่เอามาใช้ใน Apps Script ไม่ได้

6.1 ส่วนที่ 7 · ใส่ทุกครั้ง

ข้อกำหนดทางเทคนิค:
- เขียนเป็น Google Apps Script web app ที่ผูกกับ Google Sheets
- แยกเป็น 2 ไฟล์: Code.gs และ Index.html แสดงโค้ดเต็มทั้ง 2 ไฟล์ ไม่ตัดทอน
- ใน Code.gs ใช้ doGet() คืนค่า HtmlService.createHtmlOutputFromFile('Index') และเพิ่ม meta viewport สำหรับมือถือ
- เปิดชีตด้วย SpreadsheetApp.openById(SPREADSHEET_ID) ตั้ง SPREADSHEET_ID เป็นค่าคงที่บรรทัดแรก
- หน้าเว็บเรียกโค้ดหลังบ้านด้วย google.script.run พร้อม withSuccessHandler และ withFailureHandler
- ฟังก์ชันที่หน้าเว็บไม่ต้องเรียก ให้ตั้งชื่อลงท้ายด้วย _
- ส่งวันที่กลับไปที่หน้าเว็บเป็นข้อความที่จัดรูปแบบด้วยเขตเวลา Asia/Bangkok
- มีฟังก์ชัน setup() สำหรับรันครั้งแรก สร้างแผ่นงานและหัวคอลัมน์ให้อัตโนมัติ
- ไม่ใช้ไลบรารีหรือไฟล์จากภายนอก
- ใส่คำอธิบายภาษาไทยสั้น ๆ เหนือแต่ละฟังก์ชัน
- หลังโค้ด อธิบายทีละขั้นสำหรับมือใหม่ว่าต้องวางไฟล์ไหนตรงไหน และ Deploy อย่างไร

ทุกข้อมาจากแนวทางของ Google: doGet และ HtmlService[3][5] · google.script.run และฟังก์ชันลงท้าย _[4]

บทที่ 8

ปลอดภัยไว้ก่อน

กฎเหล็กข้อเดียวแอปที่พยาบาลสร้างเองต้อง ไม่เก็บข้อมูลที่ระบุตัวผู้ป่วยได้ เว้นแต่ฝ่าย IT และ DPO ของโรงพยาบาลอนุมัติ เพราะข้อมูลในชีตอยู่บนเซิร์ฟเวอร์ของ Google ไม่ใช่ระบบของโรงพยาบาล และข้อมูลสุขภาพเป็นข้อมูลอ่อนไหวตาม PDPA มาตรา 26[12]

ไฟจราจรข้อมูล

เขียว · เก็บได้

อุณหภูมิตู้เย็น รายการพัสดุ ผลเช็กรถ Emergency งานโครงการ

เหลือง · ระวัง

อักษรย่อเจ้าหน้าที่ จำนวนผู้ป่วยรวมต่อเวร ได้ถ้าย้อนกลับหาตัวคนไม่ได้

แดง · ห้าม

ชื่อ HN AN เลขบัตร เบอร์โทร รูปผู้ป่วย เตียง + อายุ + การวินิจฉัย

ตั้งค่าให้ปลอดภัย

  • จำกัดคนแก้ชีต: ทุกคนที่แก้ชีตได้จะเห็นและรันโค้ดได้ด้วย[6]
  • Who has access แคบที่สุด: ในหน่วยงานใช้ "Anyone within [องค์กร]" หลีกเลี่ยง "Anyone"
  • ซ่อนฟังก์ชันภายใน: ตั้งชื่อลงท้ายด้วย _[4] สำคัญมากเมื่อใช้ Execute as: Me
  • ไม่ส่ง token ไปหน้าเว็บ: Google เตือนว่า OAuth token ให้สิทธิ์เข้าถึงข้อมูลของเราได้[3]
  • กันข้อความกลายเป็นสูตร: ถ้ามีช่องข้อความอิสระ ให้สั่ง AI ป้องกันข้อความที่ขึ้นต้นด้วย = + − @
  • สำรองข้อมูล: ใช้ ไฟล์ > ประวัติเวอร์ชัน และดาวน์โหลดสำเนาตามรอบของหน่วยงาน

ตอนใช้ AI ช่วยเขียนโค้ด

ตามแนวทาง AI ฉบับ 1.0 ของ สคส. (ราชกิจจานุเบกษา 2 พ.ย. 2569)[13] Prompt และคำตอบของ AI อาจเป็นข้อมูลส่วนบุคคลได้ อย่าคัดลอกข้อมูลจริงจากชีตไปวางให้ AI คนต้องตรวจโค้ดและผลลัพธ์จริง และถ้าเผลอป้อนข้อมูลผู้ป่วย ให้แจ้ง DPO ทันที เพราะองค์กรต้องแจ้งเหตุภายใน 72 ชั่วโมง (มาตรา 37 (4))

ความปลอดภัยทางคลินิกแอปที่ทำเองเป็นเครื่องมือช่วยงาน ไม่ใช่ระบบเวชระเบียน (HIS) ต้องมีผู้รับผิดชอบดูแล และมีแผนสำรอง เช่น ใบบันทึกกระดาษ เมื่อเน็ตหรือ Google ใช้งานไม่ได้
